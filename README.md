# Blog educativo: uso adecuado del repelente para mosquitos

Proyecto de 1.º BGU, Unidad Educativa de las Fuerzas Armadas Liceo Naval de Guayaquil «Cmdte. Rafael Andrade Lalama».

## Estructura
```
proyecto-repelente-mosquitos/
├── index.html          → página única del blog (todas las secciones)
├── css/estilos.css     → estilos visuales del sitio
├── js/script.js        → menú móvil, barra de progreso, botón "volver arriba"
├── img/LEEME.txt       → guía para agregar las fotografías reales
└── README.md
```

## Uso
No requiere instalar nada: abre `index.html` en el navegador o publica la carpeta en GitHub Pages
(Settings → Pages → rama `main`, carpeta `/root`).

## Para agregar más fotos
Guarda las imágenes en `img/` y añádelas en la Sección 04 de `index.html` (ver `img/LEEME.txt`).
